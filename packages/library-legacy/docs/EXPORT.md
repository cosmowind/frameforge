# 导出 TXT 功能说明

## 概述

导出功能将视频数据按用户选择的列和行导出为纯文本文件，每行对应一个单元格的值（n×m 矩阵导出 n×m 行）。

## 使用方式

### 1. 打开导出对话框
点击工具栏右侧的 **"导出TXT"** 按钮。

### 2. 选择列
在弹出对话框的"选择列"区域，点击列名 chip 切换选中状态。
- 选中的列会以蓝色高亮显示
- 列的排列顺序即为导出时的顺序

### 3. 选择行
在"选择行"区域：
- 点击 **"全部"** chip 可导出行 1～N 所有数据
- 也可单独点击某个行号 chip（如 `#3`）只导出特定行
- 支持多选

### 4. 设置分隔符（当前保留）
分隔符字段已保留但暂不影响输出（每行只输出一个单元格值）。

### 5. 执行导出
点击 **"导出"** 按钮，浏览器自动下载 `export.txt` 文件。

## 导出格式示例

原始数据：

| name | category | recorder |
|------|----------|----------|
| a1   | 高       | 张三     |
| b1   | 中       | 李四     |

选中列：`name`, `category`, `recorder`（全部行）

导出结果（9行）：
```
a1
高
张三
b1
中
李四
```

## API

### POST /api/export

**请求体（JSON）**
```json
{
  "columns": ["name", "category", "recorder"],
  "rows": [],
  "separator": "."
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| columns | string[] | 要导出的列键，按顺序排列 |
| rows | number[] | 要导出的行索引（从 0 开始），空数组表示全部 |
| separator | string | 分隔符（当前保留） |

**响应**
- 成功：返回纯文本文件（Content-Type: text/plain）
- 失败：返回 JSON `{"error": "..."}`
