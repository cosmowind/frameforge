mcap -> mp4 在线转换

浏览器上传 mcap -> 云端用 mcap2mp4_app 转码 -> 下载 mp4。

1. 选择输入文件夹（A）

点【选择文件夹】弹窗选你本地的「输入文件夹 A」（里面多个 session 子文件夹，每个含 session.json + ego_*.mcap）。建议用 Chrome / Firefox / Edge。IE 不支持。
