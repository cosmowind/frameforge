mcap -> mp4 浏览器内 remux

纯静态页 · 文件全程不离开本机 · 无网络请求

1. 选择输入文件夹 A

点【选择文件夹】选你本地的「输入文件夹 A」（里面多个 session 子文件夹，每个含 session.json + ego_*.mcap）。 建议 Chrome / Edge / Firefox；IE 不支持。

尚未选择文件夹。

    2. 转换

    转换在浏览器里直接跑，纯 JS 重写 MP4 容器（不重新编码）。大文件（2GB+）会优先尝试 File System Access API 直接流式写盘；不支持时退回 Blob 下载。
