# 快速打包指南

## ⚠️ 重要：首次打包必读

本应用已将 FFmpeg 打包进来，用户无需单独安装！

但是**首次打包前**，你需要先安装 FFmpeg 依赖：

```bash
# 运行这个脚本（只需要运行一次）
install-ffmpeg.bat
```

这会下载约 50-100MB 的 FFmpeg 二进制文件，请耐心等待。

## 一键打包命令

安装 FFmpeg 依赖后，运行：

```bash
npm run dist
```

或者使用批处理脚本：

```bash
package-app.bat
```

这个命令会：
1. 自动构建应用（前端 + 后端）
2. 使用 electron-builder 打包
3. 生成 Windows 安装程序

## 打包步骤详解

### 第一步：确保依赖已安装
```bash
npm install
```

### 第二步：执行打包
```bash
npm run dist
```

### 第三步：等待打包完成
- 首次打包会下载 Electron 二进制文件（约 100MB），需要等待较长时间
- 后续打包会快很多
- 打包过程中会显示进度信息

### 第四步：获取安装程序
打包完成后，在 `release` 目录找到：
```
release/
└── 视频分割工具 Setup 1.0.0.exe  （约 200-250MB）
```

## 为什么安装包这么大？

安装包包含：
- ✅ Electron 运行时（约 100MB）- 完整的浏览器引擎
- ✅ Node.js 运行时
- ✅ FFmpeg 和 FFprobe（约 50-100MB）- 视频处理工具
- ✅ 应用代码和所有依赖

**好处**：用户安装后即可使用，无需安装任何额外软件！

## 常见问题

### Q1: 打包失败，提示找不到文件
**A**: 先运行 `npm run build` 确保构建成功

### Q2: 打包很慢
**A**: 首次打包需要下载 Electron 二进制文件，请耐心等待。后续打包会快很多。

### Q3: 安装程序很大（200-250MB）
**A**: 这是正常的。Electron 应用包含：
- 完整的 Chromium 浏览器引擎（约 100MB）
- Node.js 运行时
- FFmpeg 和 FFprobe 视频处理工具（约 50-100MB）
- 应用代码和资源
- 所有依赖库

**优点**：用户无需安装任何额外软件，开箱即用！

### Q4: 如何减小安装包大小
**A**: 可以考虑：
- 使用 asar 打包（已默认启用）
- 移除不必要的依赖
- 使用代码分割
- 但通常不建议过度优化，因为会影响开发体验

### Q5: 能否打包为绿色版（免安装）
**A**: 可以，修改 package.json 中的配置：
```json
"win": {
  "target": ["portable"]
}
```
然后运行 `npm run dist`

### Q6: 如何打包 macOS 或 Linux 版本
**A**: 
- macOS: 需要在 macOS 系统上打包
- Linux: 可以在 Windows 上交叉编译
- 修改 package.json 中的 target 配置

### Q7: 打包后的程序能在其他电脑运行吗
**A**: 可以！安装程序包含所有依赖，包括 FFmpeg。用户无需安装 Node.js、FFmpeg 或其他环境。

### Q8: FFmpeg 是否已经打包进去了
**A**: 是的！使用 `@ffmpeg-installer/ffmpeg` 和 `@ffprobe-installer/ffprobe` 包，FFmpeg 已经完全打包进应用。用户安装后即可使用所有视频处理功能。

### Q9: 如何更新版本号
**A**: 修改 package.json 中的 version 字段：
```json
"version": "1.0.1"
```
