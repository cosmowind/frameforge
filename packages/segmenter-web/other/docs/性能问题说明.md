# 性能问题说明与解决

## 问题描述

打包后的应用在读取视频时非常慢，一直显示"处理中"，但在开发环境（`npm start`）运行时速度很快。

## 问题原因

在 Electron 打包后，应用代码被打包进 `app.asar` 归档文件中。但是二进制文件（如 FFmpeg 和 FFprobe）需要被解压到 `app.asar.unpacked` 目录才能执行。

原来的代码：
```typescript
const ffmpegPath = require('@ffmpeg-installer/ffmpeg').path;
const ffprobePath = require('@ffprobe-installer/ffprobe').path;
```

这会返回 `app.asar` 内的路径，但二进制文件实际在 `app.asar.unpacked` 目录中，导致找不到文件或执行失败。

## 解决方案

修改 `src/main/main.ts`，将路径中的 `app.asar` 替换为 `app.asar.unpacked`：

```typescript
// 开发环境或打包后都能正确获取路径
ffmpegPath = require('@ffmpeg-installer/ffmpeg').path.replace('app.asar', 'app.asar.unpacked');
ffprobePath = require('@ffprobe-installer/ffprobe').path.replace('app.asar', 'app.asar.unpacked');
```

同时添加了文件存在性验证和错误处理。

## 验证修复

### 1. 查看控制台日志

打包后的应用启动时，打开开发者工具（如果启用），查看控制台输出：

```
FFmpeg 路径: C:\...\app.asar.unpacked\node_modules\@ffmpeg-installer\...
FFprobe 路径: C:\...\app.asar.unpacked\node_modules\@ffprobe-installer\...
```

确保路径包含 `app.asar.unpacked` 而不是 `app.asar`。

### 2. 测试视频加载

1. 打开应用
2. 选择一个视频文件
3. 应该能快速提取视频信息（几秒内完成）

### 3. 检查文件结构

安装后的应用目录结构：
```
应用安装目录/
└── resources/
    ├── app.asar                    # 应用代码（压缩）
    └── app.asar.unpacked/          # 二进制文件（未压缩）
        └── node_modules/
            ├── @ffmpeg-installer/
            │   └── win32-x64/
            │       └── ffmpeg.exe
            └── @ffprobe-installer/
                └── win32-x64/
                    └── ffprobe.exe
```

## 其他可能的性能问题

### 1. 视频文件太大

- **症状**: 大视频文件（>2GB）加载很慢
- **解决**: 这是正常的，FFprobe 需要扫描整个文件
- **建议**: 提示用户等待，或添加进度指示器

### 2. 网络驱动器

- **症状**: 从网络驱动器读取视频很慢
- **解决**: 建议用户将视频复制到本地磁盘

### 3. 杀毒软件

- **症状**: 首次运行时很慢
- **原因**: 杀毒软件扫描 FFmpeg 可执行文件
- **解决**: 将应用添加到杀毒软件白名单

### 4. 磁盘性能

- **症状**: 机械硬盘上运行很慢
- **解决**: 建议使用 SSD

## 总结

这个问题是由于 Electron 打包机制导致的。通过正确处理 `app.asar.unpacked` 路径，FFmpeg 和 FFprobe 现在可以正常工作，视频加载速度应该和开发环境一样快了。
