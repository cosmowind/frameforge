========================================
快速打包指南（推荐方法）
========================================

不要用管理员权限运行批处理文件！
直接在项目目录打开命令行窗口。

方法1：在项目目录打开 PowerShell/CMD
----------------------------------------
1. 在文件资源管理器中打开项目文件夹
2. 在地址栏输入 "cmd" 然后按回车
3. 运行命令：npm run dist

方法2：使用 VS Code 终端
----------------------------------------
1. 用 VS Code 打开项目
2. 按 Ctrl + ` 打开终端
3. 运行命令：npm run dist

方法3：使用批处理脚本（不要用管理员权限）
----------------------------------------
1. 双击 package-app.bat（普通方式，不要右键管理员）
2. 如果提示权限问题，忽略即可（已禁用代码签名）

========================================
完整步骤
========================================

步骤1：打开项目目录的命令行
在项目文件夹地址栏输入 "cmd" 按回车

步骤2：运行打包命令
npm run dist

步骤3：等待完成
首次打包约 10-20 分钟
后续打包约 3-5 分钟

步骤4：获取安装程序
在 release 文件夹找到：
视频分割工具 Setup 1.0.0.exe

========================================
常见问题
========================================

Q: 为什么不能用管理员权限？
A: 管理员权限会改变工作目录到 C:\Windows\System32
   导致找不到 package.json

Q: 如果还是有权限问题怎么办？
A: 已经禁用了代码签名，不需要管理员权限了

Q: 打包很慢怎么办？
A: 首次打包需要下载 Electron（108MB），请耐心等待
   后续打包会快很多
