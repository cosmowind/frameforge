# 配置文件说明

## 根目录配置文件

项目根目录的配置文件说明：

### TypeScript 配置

#### tsconfig.json
主 TypeScript 配置文件，用于整个项目。

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "jsx": "react-jsx",
    // ...
  }
}
```

#### tsconfig.main.json
主进程（Electron）的 TypeScript 配置。

#### tsconfig.node.json
Node.js 环境的 TypeScript 配置。

### 构建工具配置

#### vite.config.ts
Vite 构建工具配置，用于渲染进程的构建。

#### postcss.config.js
PostCSS 配置，用于 CSS 处理。

#### tailwind.config.js
Tailwind CSS 配置。

### 代码质量配置

#### .eslintrc.json
ESLint 代码检查配置。

#### .prettierrc
Prettier 代码格式化配置。

### 包管理配置

#### package.json
项目依赖和脚本配置。

#### package-lock.json
依赖锁定文件（自动生成）。

#### .npmrc
npm 配置文件。

### 版本控制

#### .gitignore
Git 忽略文件配置。

## 配置文件位置

### 根目录（必须）
以下文件必须在根目录：
- package.json
- tsconfig.json
- tsconfig.main.json
- tsconfig.node.json
- vite.config.ts
- tailwind.config.js
- postcss.config.js
- .eslintrc.json
- .prettierrc
- .npmrc
- .gitignore

### other/config/
以下文件在 other/config/：
- electron-builder.yml - Electron 打包配置

## 修改配置

### 修改 TypeScript 配置
编辑 `tsconfig.json` 或相应的配置文件。

### 修改构建配置
编辑 `vite.config.ts`。

### 修改打包配置
编辑 `other/config/electron-builder.yml`。

### 修改代码规范
编辑 `.eslintrc.json` 和 `.prettierrc`。

## 注意事项

1. **不要移动根目录配置文件** - 这些文件必须在根目录才能被工具识别
2. **不要手动修改 package-lock.json** - 这是自动生成的
3. **修改配置后重新构建** - 运行 `npm run build`
