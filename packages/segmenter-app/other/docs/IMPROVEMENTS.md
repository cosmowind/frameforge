## 使用说明

### 视频缩放
1. 打开右侧规则面板
2. 在顶部找到"视频缩放"滑块
3. 拖动滑块调整视频大小（50%-150%）

### 添加片段
- **方式1**: 点击时间轴上方的"添加片段 (A)"按钮
- **方式2**: 按键盘 'A' 键
- 片段会在当前播放位置添加，默认15秒长度

### 调整片段
- 点击并拖动片段的左右边缘来调整开始和结束时间
- 边缘检测范围为15px，更容易操作
- 点击片段中间区域可以选中片段
- 点击空白处取消选择

### 时间轴缩放和滚动
1. 使用时间轴上方的滑块精确调节缩放级别
2. 缩放范围：0.1x（查看长视频全貌）到 10x（精确编辑）
3. 实时显示当前缩放倍数（如 "1.5x"）
4. 放大后，时间轴会出现横向滚动条
5. 拖动滚动条查看完整时间轴

### 规则面板控制
- **隐藏**: 点击面板右上角的眼睛图标
- **显示**: 点击右下角的浮动按钮

### 播放同步
- **同步模式**: 点击时间轴片段时，视频会自动跳转到该片段开始位置
- **非同步模式**: 可以自由控制播放位置，不受时间轴选择影响
- 点击"同步"按钮切换模式

### 撤销操作
- 按 Ctrl + Z 撤销上一次操作
- 会显示提示消息确认撤销成功
- 如果没有可撤销的操作，会提示"没有可撤销的操作"

### 审核页面
- 审核页面与分割页面功能完全相同
- 包含视频播放器、时间轴和片段控制
- 可以在审核时继续编辑和调整片段
- 所有快捷键和操作方式保持一致

## 技术实现细节

### 视频缩放的正确实现
问题分析：
- **错误方式1**: 只调整容器高度 → 视频本身不缩放
- **错误方式2**: 只使用 transform scale → 视频缩放但占据空间不变，下方组件不上移

正确方式：
```typescript
// 1. 获取视频播放器的原始高度
const [videoNaturalHeight, setVideoNaturalHeight] = React.useState(0);

// 2. 外层容器高度 = 原始高度 × 缩放比例
<div style={{
  height: `${videoNaturalHeight * (videoScale / 100)}px`,
  overflow: 'visible'
}}>
  {/* 3. 内层使用 transform scale 进行视觉缩放 */}
  <div style={{ 
    transform: `scale(${videoScale / 100})`, 
    transformOrigin: 'top center'
  }}>
    <VideoPlayer />
  </div>
</div>
```

关键点：
- 外层容器控制实际占据的布局空间
- 内层 transform 控制视觉缩放效果
- 两者结合才能让下方组件正确上移

### 改进的片段添加
```typescript
// 键盘监听
useEffect(() => {
  const handleKeyDown = (e: KeyboardEvent) => {
    if (e.key === 'a' || e.key === 'A') {
      const currentTime = videoElement.currentTime;
      const duration = Math.min(15, currentVideo.duration - currentTime);
      addSegment(currentTime, currentTime + duration);
    }
  };
  window.addEventListener('keydown', handleKeyDown);
  return () => window.removeEventListener('keydown', handleKeyDown);
}, [currentVideo, videoElement, addSegment]);

// 点击空白处只选择/取消选择，不添加片段

}
```

## 注意事项

1. **视频缩放**: 缩放只影响显示大小，不影响实际视频分辨率
2. **时间轴滚动**: 缩放比例大于 1x 时显示滚动条，可以精确调节到 0.1x - 10x 之间任意值
3. **撤销限制**: 最多保存50步历史记录
4. **同步状态**: 手动拖动进度条会自动解除同步状态
5. **添加片段**: 按 'A' 键或点击按钮在当前播放位置添加片段
6. **边缘拖动**: 15px的检测范围让拖动更容易，不会误触添加片段
