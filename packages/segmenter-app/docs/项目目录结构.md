## 核心目录说明

### src/ - 源代码
所有应用代码都在这里，分为主进程和渲染进程。

### docs/ - 核心文档
**最重要的文档目录**，包含：
- 项目结构
- 功能清单
- 错误记录
- 需求记录
- 代码规范

其他地方应该引用这些文档，避免内容重复。

### other/ - 其他文件
非核心的辅助文件，包括：
- 脚本文件
- 配置文件
- 辅助文档

## 文档引用规范

在其他文件中引用核心文档：

```markdown
详细信息请查看：[功能清单](docs/功能清单.md)
```

避免在多个地方重复相同内容。

## 自动生成目录

以下目录由工具自动生成，不要手动修改：
- `dist/` - Vite 构建输出
- `release/` - electron-builder 打包输出
- `node_modules/` - npm 依赖
- `package-lock.json` - npm 依赖锁定

## 配置文件说明

根目录的配置文件必须保留在根目录，不能移动：

### TypeScript 配置
- `tsconfig.json` - 主配置
- `tsconfig.main.json` - 主进程配置
- `tsconfig.node.json` - Node.js 配置

### 构建工具配置
- `vite.config.ts` - Vite 配置
- `postcss.config.js` - PostCSS 配置
- `tailwind.config.js` - Tailwind CSS 配置

### 代码质量配置
- `.eslintrc.json` - ESLint 配置
- `.prettierrc` - Prettier 配置

### 其他配置
- `.npmrc` - npm 配置
- `.gitignore` - Git 忽略规则

详细说明请查看：[配置文件说明](../other/docs/配置文件说明.md)
