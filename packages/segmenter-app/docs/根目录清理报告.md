## 清理原则

1. **配置文件必须在根目录** - 工具需要在根目录找到配置
2. **文档集中管理** - 核心文档在 docs/，辅助文档在 other/docs/
3. **脚本集中管理** - 所有脚本在 other/scripts/
4. **配置集中管理** - 可移动的配置在 other/config/
