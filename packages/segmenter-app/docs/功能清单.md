# 功能清单

## 已完成功能

### 1. 视频加载与预览 ✅
- 支持 MP4 格式视频
- 自动提取视频信息（时长、分辨率、编码等）
- 视频播放控制（播放/暂停、进度条、音量）
- 倍速播放（0.5x - 4x）
- 全屏播放

### 2. 视频缩放功能 ✅
- 位置：右侧规则面板顶部
- 缩放范围：50% - 150%
- 使用 CSS transform scale 实现
- 缩小后下方组件自动上移填充空间

### 3. 时间轴编辑 ✅
- 可视化时间轴显示
- 时间轴缩放：0.1x - 10x（滑块精确调节）
- 横向滚动查看完整时间轴
- 拖动片段边缘调整时长
- 点击片段选中并跳转
- 实时显示当前播放位置

### 4. 片段管理 ✅
- 添加片段（按钮或 A 键）
- 删除片段
- 分割片段
- 片段验证（5-25秒规则）
- 片段列表显示
- 片段状态标识（有效/无效/警告）

### 5. 元数据管理 ✅
- 保存分割方案为 JSON
- 加载已有分割方案
- 自动关联视频和分割方案
- 元数据包含所有片段信息

### 6. 视频分割执行 ✅
- 使用 FFmpeg 进行无损分割
- 保持原始视频质量
- 自动命名输出文件
- 进度显示
- 错误处理

### 7. 规则面板 ✅
- 显示/隐藏切换
- 完整的分割规则说明
- 浮动按钮控制

### 8. 播放同步控制 ✅
- 同步/非同步模式切换
- 同步模式：点击片段自动跳转
- 非同步模式：手动控制播放

### 9. 撤销功能 ✅
- Ctrl+Z 撤销操作
- 支持撤销：添加、删除、修改、分割片段
- 最多保存 50 步历史

### 10. 审核页面 ✅
- 完整的视频预览和编辑功能
- 包含视频播放器、时间轴、片段控制
- 保留所有编辑能力

### 11. FFmpeg 集成 ✅
- 完全集成 FFmpeg 和 FFprobe
- 用户无需单独安装
- 自动处理打包路径问题
- 约 50-100MB 二进制文件

### 12. 应用打包 ✅
- Windows NSIS 安装程序
- 自定义安装路径
- 桌面和开始菜单快捷方式
- 完整卸载支持
- 无需额外依赖

## 技术特性

### 前端技术栈
- React 18 + TypeScript
- Ant Design 5 UI 组件
- Tailwind CSS 3 样式
- Zustand 4 状态管理
- Vite 5 构建工具

### 后端技术栈
- Electron 28 桌面框架
- Node.js 运行时
- FFmpeg 视频处理
- TypeScript 类型安全

### 性能优化
- 视频信息缓存
- 增量渲染
- 防抖处理
- 路径优化（app.asar.unpacked）
