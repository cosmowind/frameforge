## 打包相关

### 1. 代码签名权限错误

**问题描述**：
```
ERROR: Cannot create symbolic link : 客户端没有所需的特权
```

打包时 electron-builder 尝试解压代码签名工具，但因为创建符号链接需要管理员权限而失败。

**错误原因**：
- Windows 上创建符号链接需要管理员权限
- electron-builder 默认会下载 winCodeSign 工具用于代码签名

**解决方案**：
1. 创建 `electron-builder.yml` 配置文件
2. 添加 `signAndEditExecutable: false` 禁用代码签名
3. 使用 `--config electron-builder.yml` 参数打包

**相关文件**：
- `electron-builder.yml`
- `package.json` (scripts.dist)

**参考文档**：[打包说明](../other/docs/BUILD.md)

---

### 2. 管理员权限导致工作目录错误

**问题描述**：
```
npm error path C:\Windows\System32\package.json
npm error errno -4058
```

以管理员身份运行批处理文件时，工作目录变成了 `C:\Windows\System32`。

**错误原因**：
- 以管理员身份运行时，默认工作目录是系统目录
- 批处理脚本没有切换到正确的项目目录

**解决方案**：
在批处理脚本开头添加：
```batch
REM 切换到脚本所在目录
cd /d "%~dp0"
```

**相关文件**：
- `other/scripts/package-app.bat`
- `other/scripts/install-ffmpeg.bat`

## 性能问题

### 3. 打包后视频加载缓慢

**问题描述**：
打包后的应用读取视频非常慢，一直显示"处理中"，但开发环境运行正常。

**错误原因**：
- 打包后，FFmpeg/FFprobe 二进制文件被解压到 `app.asar.unpacked` 目录
- 代码中使用的路径还是指向 `app.asar`，导致找不到文件

**解决方案**：
修改 `src/main/main.ts`，将路径中的 `app.asar` 替换为 `app.asar.unpacked`：

```typescript
ffmpegPath = require('@ffmpeg-installer/ffmpeg').path
  .replace('app.asar', 'app.asar.unpacked');
ffprobePath = require('@ffprobe-installer/ffprobe').path
  .replace('app.asar', 'app.asar.unpacked');
```

**相关文件**：
- `src/main/main.ts`
- `electron-builder.yml` (asarUnpack 配置)

**参考文档**：[性能问题说明](../other/docs/性能问题说明.md)

## 视频缩放

### 4. 视频缩放后空间未填充

**问题描述**：
使用 CSS `transform: scale()` 缩放视频后，视频在视觉上缩小了，但在布局中仍占据原来的空间，下方组件不会上移。

**错误原因**：
- CSS `transform` 只影响视觉效果，不影响布局流
- 需要同时调整容器的实际高度

**错误尝试**：
1. 只调整容器高度 → 视频被裁剪而不是缩放
2. 只使用 transform scale → 视频缩放但占据空间不变

**正确解决方案**：
同时做两件事：
1. 外层容器：控制实际占据的布局空间
2. 内层 transform：控制视觉缩放效果

```typescript
// 1. 获取视频播放器的原始高度
const [videoNaturalHeight, setVideoNaturalHeight] = useState(0);

// 2. 外层容器高度 = 原始高度 × 缩放比例
<div style={{
  height: `${videoNaturalHeight * (videoScale / 100)}px`
}}>
  {/* 3. 内层使用 transform scale */}
  <div style={{ 
    transform: `scale(${videoScale / 100})`, 
    transformOrigin: 'top center'
  }}>
    <VideoPlayer />
  </div>
</div>
```

**相关文件**：
- `src/renderer/components/SegmentationView.tsx`

**参考文档**：[功能改进说明](../IMPROVEMENTS.md)

## 其他问题

### 5. 时间轴缩放控制不够精确

**问题描述**：
固定倍率的放大/缩小按钮（1.5x）不够灵活，用户无法精确调节缩放级别。

**解决方案**：
使用 Slider 组件替代固定倍率按钮：
- 缩放范围：0.1x - 10x
- 步长：0.1x
- 实时显示当前倍数

**相关文件**：
- `src/renderer/components/Timeline.tsx`

## 经验总结

### 打包相关
1. 不要以管理员身份运行批处理脚本
2. 批处理脚本要切换到正确的工作目录
3. 禁用代码签名可以避免权限问题
4. 二进制文件需要配置 `asarUnpack`

### 性能优化
1. 打包后要处理 `app.asar.unpacked` 路径
2. 添加文件存在性验证和错误处理
3. 使用控制台日志帮助调试

### UI 布局
1. CSS `transform` 不影响布局流
2. 需要同时调整容器高度和视觉缩放
3. 使用 Slider 提供更好的用户体验
